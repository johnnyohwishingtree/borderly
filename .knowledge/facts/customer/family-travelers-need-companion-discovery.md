# Fact: Family Travelers Need Obvious Companion Discovery

Family travelers (parents with children, couples) are a core use case. Adding companions/dependents must be discoverable without a dedicated onboarding screen. Currently accessible via Profile → Family Management, but this path is not obvious to new users.

The companion feature should be surfaced where it's contextually relevant — e.g., on the trip list empty state, trip creation, or profile screen — not buried in a sub-menu.
