# Submission Guide

Step-by-step walkthrough of each government portal with pre-filled values ready to copy/paste.

Each country has a submission guide defining portal steps. The guide shows CopyableField components with auto-filled values the user copies into the government website.

## Key components
- `StepCard` — individual step in the walkthrough
- `CopyableField` — tap to copy a value to clipboard (auto-clears after 60s)
- `GuideProgress` — progress indicator
