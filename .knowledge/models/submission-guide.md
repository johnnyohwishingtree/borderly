# Model: Submission Guide

## Entities

### Portal
- Properties: `countryCode`, `portalName`, `url`, `requiresAccount`
- Examples: Visit Japan Web, SG Arrival Card, Malaysia MDAC

### SubmissionStep
- Properties: `stepNumber`, `title`, `description`, `copyableFields[]`, `fieldsOnThisScreen[]`, `automation.url`
- Each step maps to a portal page; `fieldsOnThisScreen` scopes auto-fill to that step's fields
- `automation.url` enables step detection by matching the current WebView URL

### PageType
- Values: `unknown`, `auth`, `captcha`, `form`
- Detected from HTML content + form field count
- Form fields take priority over auth patterns (government portals mix login text on form pages)

### CopyableField
- Properties: `label`, `value`, `fieldId`
- User taps to copy value to clipboard for pasting into portal (fallback when auto-fill unavailable)

### FieldSpec
- Properties: `id`, `selector`, `value`, `inputType`
- Generated by coordinator from filled form + automation script field mappings
- Used to build JavaScript auto-fill scripts injected into WebView

### PortalCredential
- Properties: `portalCode`, `username`, `password`
- Storage: OS Keychain (credentials are sensitive)
- Resolved via `credentialResolver` respecting family policy

## Relationships
```
Country 1──1 Portal
Portal 1──* SubmissionStep (ordered)
SubmissionStep 1──* CopyableField
SubmissionStep 1──* FieldSpec (generated at runtime from auto-fill)
Portal 1──1 PortalCredential (optional)
```

## Coordinator Facade

`submissionCoordinator` is the single entry point. Screens and hooks never import individual submission services directly.

| Capability | Methods | Delegates to |
|---|---|---|
| Page detection | `detectPageType()`, `detectStep()` | `pageDetector`, schema `submissionGuide` |
| Auto-fill | `buildAutoFillSpecs()`, `buildAutoFillScript()`, `isAutoFillSufficient()` | `formFiller`, `automationScriptRegistry`, `formEngine` |
| Auto-login | `resolveCredential()`, `buildLoginScript()`, `storeCredential()` | `credentialResolver`, `autoLogin`, `keychainService` |
| QR detection | `getQRDetectionScript()` | `qrDetection` |
| Copy-paste fallback | `generateFilledForm()` | `formEngine` |

## Invariants
- Clipboard auto-clears after 60 seconds when passport data is copied
- Portal communication is direct device-to-government (no intermediary server)
- Credential storage in Keychain only
- Form field count > 0 takes priority over auth pattern matching in page detection
- Auto-fill field mapping keys must match schema field IDs exactly (silent skip on mismatch)
- Auto-fill sufficiency threshold: >= 50% fill rate
