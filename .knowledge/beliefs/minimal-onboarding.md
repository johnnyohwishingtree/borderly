# Belief: Onboarding Should Be Minimal — Passport + Go

Users should reach the main app in under 5 screens. The only essential onboarding step is passport scanning — everything else (tutorial, companions, biometric, notifications) can be deferred to first use or settings.

Rationale:
- Tutorial: the welcome screen already explains the concept visually
- Companions: only relevant for family trips — ask when creating a multi-traveler trip
- Biometric: default to on, let users disable in settings
- Notifications: ask at the first relevant moment (trip deadline approaching), not upfront

Certainty: High — based on mobile UX best practices and the observation that 9 onboarding screens before value is excessive.
