## Fix attempt 1 — 2026-03-21

### Root cause
`e2e/tests/trip-detail.spec.ts:164` — `TripDetailScreen renders correctly for a trip with one leg` — was using `page.getByText('Detail Test Trip')` and `page.getByText('Overall Progress')` after navigating to TripDetailScreen.

React Navigation keeps the previous screen (TripList) in the DOM after navigation, so `getByText('Detail Test Trip')` matched the same text in both screens. Playwright's strict-mode locator throws when a locator resolves to more than one element, causing the test to fail.

### Fix
Removed the redundant `getByText('Detail Test Trip')` assertion (already confirmed by `goToTripDetail` checking for 'Itinerary'). Replaced `getByText('Overall Progress')` with `getByTestId('trip-readiness-summary')` which is unique and already present in the same section.
