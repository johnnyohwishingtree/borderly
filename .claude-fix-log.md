# Fix Log

## Round 1

**Problem:** E2E test `Trip and Submit Flow` failing in `createJapanTrip` helper.

**Root cause:** `AddressAutocomplete` component was added for accommodation address fields. This component renders individual sub-fields with testIDs like `${testID}-line1`, `${testID}-city`, `${testID}-postal-code`. The E2E helper `actions.ts` was still using old flat testIDs (`leg-0-accommodation-address`, `leg-0-accommodation-city`, `leg-0-accommodation-postal-code`).

**Fix:** Updated `e2e/helpers/actions.ts` `createJapanTrip` function to use the new sub-field testIDs:
- `leg-0-accommodation-address` → `leg-0-accommodation-address-line1`
- `leg-0-accommodation-city` → `leg-0-accommodation-address-city`
- `leg-0-accommodation-postal-code` → `leg-0-accommodation-address-postal-code`

**Checks:** `pnpm typecheck` ✅, `pnpm test` ✅ (143 suites, 4208 tests)
**Status:** Pushed
