# Fix Log

## Attempt 1 — 2026-03-22

### Problem
Two E2E tests in `e2e/tests/app-lock.spec.ts` failed:
- `LockScreen renders when app is locked after onboarding`
- `Normal navigation reappears after unlock`

### Root Cause
`LockScreen` accesses `Keychain.BIOMETRY_TYPE.FACE_ID` during render (inside `getBiometryLabel`). The E2E web mock at `e2e/mocks/keychain.js` was missing `BIOMETRY_TYPE`, so `Keychain.BIOMETRY_TYPE` was `undefined`. Accessing `.FACE_ID` on `undefined` threw a TypeError, crashing the component before `testID="lock-screen"` could be rendered.

### Fix
Added `BIOMETRY_TYPE` (with `TOUCH_ID`, `FACE_ID`, `FINGERPRINT`, `FACE`, `IRIS`) and `getGenericPassword`/`hasGenericPassword`/`setGenericPassword` to `e2e/mocks/keychain.js`.
