# Fix Log

## Attempt 1 — 2026-03-22

### Problem
Two E2E tests in `e2e/tests/deadline-reminders.spec.ts` were failing:
- `notification permission screen is reachable from onboarding flow`
- `notification permission screen: Allow Notifications button is present and enabled`

### Root Cause
`BiometricSetupScreen.handleSkip()` calls `Alert.alert()` which renders as `window.confirm()` in the web E2E environment (via the custom alert mock). The tests clicked "Skip for Now" but didn't handle the resulting browser confirm dialog, so navigation to `NotificationPermissionScreen` never fired.

### Fix
Added `page.on('dialog', dialog => dialog.accept())` immediately after `page.goto('/')` in both failing tests so the confirm dialog is auto-accepted and navigation proceeds.
