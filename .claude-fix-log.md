## Attempt 1 — 2026-03-22

### Root Cause
The two failing E2E tests both used `page.getByText('Restore from Backup').first()` to verify navigation to RestoreBackupModal. Playwright's `getByText()` is case-insensitive and does substring matching by default. The WelcomeScreen contains the text "Restore from backup" (lowercase 'b') which matched the query. Since the WelcomeScreen is still in the DOM (behind the modal in the navigation stack), but hidden, `.first()` returned that hidden element, causing the assertion to fail.

### Fix
Scoped the text assertion within the `restore-backup-screen` container:
- `page.getByText('Restore from Backup').first()` → `page.getByTestId('restore-backup-screen').getByText('Restore from Backup').first()`
