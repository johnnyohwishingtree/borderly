# Fix Log

## Fix attempt 1 (2026-03-22)

### Problem
Two E2E tests failing in `deadline-reminders.spec.ts`:
- `notification permission screen is reachable from onboarding flow`
- `notification permission screen: Allow Notifications button is present and enabled`

### Root Cause
`BiometricSetupScreen`'s "Skip for Now" button calls `Alert.alert()` which uses `window.confirm()` on web. The new tests in `deadline-reminders.spec.ts` were missing a `page.on('dialog', dialog => dialog.accept())` handler. Without it, Playwright auto-dismisses the confirm dialog (returns `false`), the cancel action fires, and navigation to `NotificationPermission` never happens.

The existing `onboarding.spec.ts` tests had this handler in `beforeEach` — the new tests simply omitted it.

### Fix
Added `test.beforeEach` with `page.on('dialog', dialog => dialog.accept())` to the `Deadline Reminders — Notification Permission Screen` describe block in `e2e/tests/deadline-reminders.spec.ts`.
