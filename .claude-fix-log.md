## Fix 1 — 2026-03-22

**Error:** `TS2556: A spread argument must either have a tuple type or be passed to a rest parameter` in `__tests__/hooks/useTripReadiness.test.ts:51`

**Root cause:** The `mockScheduleReadinessCheck` was declared as `jest.fn(() => Promise.resolve())` with 0 parameters. The mock factory spread `(...args: any[]) => mockScheduleReadinessCheck(...args)` caused TS2556 because spreading `any[]` into a 0-arg function isn't allowed in strict mode.

**Fix:**
1. Changed mock declaration to accept 2 parameters: `jest.fn((_trip: unknown, _readiness: unknown) => Promise.resolve())`
2. Changed factory to pass args explicitly: `(trip: unknown, readiness: unknown) => mockScheduleReadinessCheck(trip, readiness)`
