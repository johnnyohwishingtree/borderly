# Fix Log

## Fix attempt 1 — 2026-03-22

### Problem
Two E2E tests in `e2e/tests/deadline-reminders.spec.ts` were failing:
- `Deadline Reminders — Notification Permission Screen › notification permission screen is reachable from onboarding flow`
- `Deadline Reminders — Notification Permission Screen › notification permission screen: Allow Notifications button is present and enabled`

### Root Cause
Both tests registered `page.on('dialog', dialog => dialog.accept())` **twice**:
1. In the `test.describe` `beforeEach` hook
2. Again in the test body itself

When the BiometricSetup "Skip for Now" dialog (a `window.confirm`) fired, both handlers attempted to call `dialog.accept()`. The first call succeeded; the second call on an already-handled dialog threw an error that failed the test.

### Fix
Removed the duplicate `page.on('dialog', ...)` registration from the test bodies (lines 151 and 194 in the original). The `beforeEach` handler is sufficient.
