# Fix Log

## Fix 1 — 2026-03-23

### Problem
E2E test `tripAndSubmit.spec.ts` was failing at `createJapanTrip` helper where it called:
```js
await page.getByTestId('leg-0-accommodation-name').fill('Park Hyatt Tokyo');
```

### Root Cause
`CreateTripScreen` was updated to use `AccommodationAutocomplete` instead of a plain `Input` for the hotel name field. `AccommodationAutocomplete` wraps `Input` with a nested testID: the outer `View` gets `testID={testID}` (e.g., `leg-0-accommodation-name`) but the actual `Input` gets `testID="${testID}-input"` (e.g., `leg-0-accommodation-name-input`).

Playwright's `fill()` requires a true input element and fails on a `div/View`.

### Fix
Updated `e2e/helpers/actions.ts` line 90:
- Before: `page.getByTestId('leg-0-accommodation-name').fill(...)`
- After: `page.getByTestId('leg-0-accommodation-name-input').fill(...)`
